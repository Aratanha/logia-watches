# LOGIA — Haute Horlogerie & Fine Wristwatches

An interactive e-commerce storefront for **Logia**, a luxury wristwatch brand featuring a **Navy-Blue & Off-White** aesthetic palette.

## Features
- **Live Mechanical Hero Watch**: Interactive SVG watch synchronized to local time with customizable dial finishes (Abyssal Navy, Grand Feu Off-White, Aegean Slate Blue).
- **Catalog Search & Filtering**: Instant search across watch models, reference numbers, calibres, and categories, plus category pills (*Automatic*, *Chronograph*, *Diver*, *Dress*, *GMT*), max-price slider, wishlist filtering, and sorting.
- **Watch Quick-View & Strap Customizer**: Inspect movement specs and select bespoke straps before adding to your bag.
- **Shopping Cart ("Acquisition Bag")**: Slide-over drawer with quantity controls, promo code support (`LOGIA10`, `HOROLOGY`), and order checkout.
- **User Settings ("Collector Settings")**: Persistent user preferences for profile details, wrist sizing, live multi-currency conversion (`USD`, `EUR`, `GBP`, `CHF`, `BRL`), **Midnight Navy** theme mode toggle, 24-hour time format, and order history.

## Project Structure
- `index.html` — Main storefront layout and interactive drawers/modals
- `styles.css` — Navy-blue and off-white design system & responsive layout
- `app.js` — Catalog data, SVG watch renderer, search/filter engine, cart, and user settings state
